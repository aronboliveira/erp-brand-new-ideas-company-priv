# OOM Fixes & Test Session — 2026-03-12

## Root Cause: PHP CLI memory_limit = -1 (UNLIMITED)

The system-wide PHP 8.4 CLI configuration at `/etc/php/8.4/cli/php.ini` had
`memory_limit = -1`, meaning any PHP process (PHPUnit, PHPStan, artisan) could
consume unlimited RAM. With 207 database migrations and heavy Eloquent model
hydration, PHPUnit processes regularly hit 2-4GB and crashed VSCode via
systemd-oomd (which preferentially killed VSCode over PHP due to `oom_score_adj`).

## Fixes Applied

### 1. System PHP CLI Memory Limit

- **File:** `/etc/php/8.4/cli/php.ini`
- **Change:** `memory_limit = -1` → `memory_limit = 2G`

### 2. PHPUnit Memory Guard

- **File:** `phpunit.xml`
- **Change:** Added `<ini name="memory_limit" value="2G"/>`, commented out `<coverage>` block

### 3. Composer Script Guards

- **File:** `composer.json`
- **Change:** Added `-d memory_limit=512M` to all 18+ `test-php*` scripts

### 4. earlyoom Installation

- **Package:** earlyoom 1.8.2
- **Config:** `/etc/default/earlyoom`
- **Settings:** Prefer killing php/phpunit/node, avoid killing Xorg/gnome-shell/code, trigger at 5% free RAM

### 5. Deal::labels() Infinite Recursion Fix

- **Files:** `app/Models/Activity/Deal.php`, `app/Models/Activity/Lead.php`
- **Root Cause:** `labels()`, `products()`, `sources()` methods shared names with database columns. When the attribute was absent (e.g., `Deal::factory()->create()`), `getAttribute('labels')` treated the method as a relation since `method_exists($this, 'labels')` was true, calling `$this->labels()`, which in turn called `$this->getAttribute('labels')` — infinite recursion.
- **Fix:** Changed to `$this->getAttributes()['labels'] ?? null` to bypass Eloquent's relation-resolution fallback.
- **Impact:** DealFileTest went from OOM at 2GB+ to passing at 87MB.

### 6. BankTransferPaymentController Fix

- **File:** `app/Http/Controllers/Bills/BankTransferPaymentController.php`
- **Bug:** `Utility::uploadFile()` returns `array{flag, msg, url}` but result was assigned directly to `$path`.
- **Fix:** Extract `$result['url']` and check `$result['flag']` for failure.
