TypeScript Build Test Harness

Test pages for validating compiled TypeScript output (ts/dist/)

How it works: Each test page loads the compiled JavaScript from ts/dist/ and verifies it executes correctly against mock DOM elements that match the production Blade templates.

Quick Reference

Server URLs
  • /harness/ - Test pages directory
  • /dist/ - Compiled TypeScript output
Running Tests
# Start server
cd ts/tests
node serve-harness.cjs

# Run Playwright tests
cd ts
npx playwright test --config=playwright.harness.config.ts
