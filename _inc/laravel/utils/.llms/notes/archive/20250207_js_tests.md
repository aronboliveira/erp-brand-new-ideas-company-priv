## Setup Approach

`public/js/custom.js` is a plain browser script (not a module). Tests use:

1. **Real jQuery** via `npm install --save-dev jquery`
2. **Indirect eval** `(0, eval)(src)` to execute custom.js in jsdom global scope
3. `"use strict"` stripped before eval so function declarations become global
4. Minimal stubs for: `bootstrap.Toast`, `Choices`, `simpleDatatables.DataTable`,
   `Swal`, `flatpickr`, and jQuery plugins (`summernote`, `tagsinput`, `tooltip`, etc.)
