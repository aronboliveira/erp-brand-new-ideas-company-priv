# Documentation Moved

To maintain a clean separation of concerns, documentation has been reorganized based on scope:

- **Laravel-specific notes** (Issues, Next Steps, Journals) have been moved to: `_inc/laravel/.notes/`
- **Monorepo-wide notes** (General architecture, utils, monorepo infra) remain in this directory: `.notes/`

## New Locations:

- `KNOWN_ISSUES.md` -> `_inc/laravel/.notes/KNOWN_ISSUES.md`

- `CURRENT_WORKING_ISSUES_WORK.md` -> `_inc/laravel/.notes/CURRENT_WORKING_ISSUES_WORK.md`
- `NEXT_STEPS.md` -> `_inc/laravel/.notes/NEXT_STEPS.md`
